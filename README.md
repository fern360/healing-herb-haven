# Healing Herb Haven

Online herb shop: 16 herbs with size pricing, a basket, a demo checkout, an "Ask the Herbalist" AI chat, and a Contact page with text-us (760) 916-2700.

- `healing-herbs-haven.html` — the shop page
- `index.html` — redirects to the shop page (for GitHub Pages)
- `logo.jpg` — logo used on the page; `logo-original.webp` — full-size original

Checkout is a demo and takes no payment. The AI chat only works when the page is opened as a Claude artifact.
